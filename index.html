01 / Sample bug ticket

I looked for bugs
on reonic.com.

I went through Reonic's English website looking for small problems and reproduced this one on 29 October 2026. Here it is as a ticket, written the way I would hand it to an engineer.

Bug Website / Blog Severity: Medium Reproduced 29 Oct 2026

Blog share buttons for LinkedIn, WhatsApp and Email share the post without its link

Where
The "Share article" box in the left sidebar of blog posts, in the wide desktop layout (I tested at 1440px). Example post: reonic.com/en-gb/blog/solar-panel-warranty-uk/
Scope
All 130 English blog posts in the sitemap. The German, French and Italian posts I checked have the same problem. The page also has a second set of share links for smaller screens, with the same empty values.
Environment
Chromium browser on macOS, window 1440 x 900. The empty links are already in the HTML the server sends, so this is not browser specific.
Steps to reproduce
  1. Open https://reonic.com/en-gb/blog/solar-panel-warranty-uk/ in a desktop browser window at least 1280px wide.
  2. In the left sidebar, scroll down to "Share article".
  3. Click the LinkedIn icon.
  4. Go back and click the WhatsApp icon. Then go back and click the Email icon.
  5. For comparison, click the Copy link icon and paste the result somewhere.
Expected result
  • LinkedIn opens its share dialog with the post URL, for example share-offsite/?url=https%3A%2F%2Freonic.com%2Fen-gb%2Fblog%2Fsolar-panel-warranty-uk%2F
  • The WhatsApp message contains the post title and the post URL.
  • The email opens with the post URL in the body.
Actual result
  • LinkedIn opens https://www.linkedin.com/sharing/share-offsite/?url= with an empty url, so there is nothing to share.
  • WhatsApp opens with the title only and no link (screenshot below).
  • The email opens with the subject filled in and an empty body.
  • Copy link works and copies https://reonic.com/en-gb/blog/solar-panel-warranty-uk/.
Notes for the engineer
  • The href values are already empty in the server HTML (checked with curl) and are still empty after the page has loaded.
  • Copy link works, so it probably reads the URL when it is clicked. The other three links look like they are built during server rendering, when the page URL is not known, and are not updated in the browser afterwards.
  • Possible fix: build all share links from the post's canonical URL. It is already correct in the page head: <link rel="canonical" href="https://reonic.com/en-gb/blog/solar-panel-warranty-uk/">
  • To check the fix: click all three buttons on one post per language and confirm the link is there.
  • How I tested: I clicked the buttons with navigation blocked so nothing was posted, then opened the WhatsApp link in a clean browser for the screenshot.
Why Medium

Three of the four share options fail on every blog post, in at least four languages. There is no data loss or security risk, and Copy link still works as a workaround, so I would not call it High.

02 / Sample release notes

One feature,
two audiences.

Reonic marks AI Single Line Diagram as new on its homepage. I wrote release notes for it twice: a short, friendly one for installers and a shorter one for colleagues inside Reonic.

What's new · For installers

Your single line diagram, drawn for you

Reonic can now create the single line diagram from the components in your planning, so you don't start from a blank page.

Want to change something? Just ask. For example:

"Add an AC surge protector at the inverter output."

The AI updates the diagram. You check the result in the editor, change anything by hand if you like, and save.

  • Built from your planned system
  • Edit by asking, or by hand
  • Save diagrams as templates and reuse them
  • Import a diagram you already have
  • Export as PDF or JPG

Available for residential projects in workspaces with AI Circuit Plan turned on.

Internal · For Reonic colleagues

AI Single Line Diagram (AI Circuit Plan)

What
Generates the diagram from the planned components. Users ask AI to add, remove or reconnect elements, then review and save in the editor. Export as JPG or PDF.
Who
Residential projects, in workspaces with AI Circuit Plan enabled.
Key message
The AI suggests the change. The installer checks it and saves.
Confirm first
Release date, markets and plans, and how a workspace gets it enabled.

03 / Working prototype

Feedback in,
tickets out.

Paste customer feedback, one message per line. The sorter files each message as a Bug, Feature request or Question and gives it a priority. It runs in your browser, with no backend and no API keys.

Made-up examples

I wrote the example messages myself to sound like solar installers. They are not from real Reonic customers. Tip: Ctrl or Cmd + Enter also sorts.

Tickets

This version uses simple keyword rules in JavaScript. A real version could use an AI model to sort each message and write the ticket title, with a person checking the result.
