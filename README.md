# Reonic x Ved

My application page for the AI Product Manager Intern (AI x Greentech) role at Reonic in Augsburg.

The page shows three things I made for this application:

1. **A sample bug ticket** for a real issue I reproduced on reonic.com on 29 October 2026: the blog share buttons for LinkedIn, WhatsApp and Email share the post without its link.
2. **Sample release notes** for AI Single Line Diagram, once for installers and once for Reonic colleagues. Based only on public information.
3. **A feedback sorter prototype** that files customer feedback as Bug, Feature request or Question and gives it a priority. It uses keyword rules in plain JavaScript, with no backend and no API keys. The example messages are made up.

## Run it

It is a single static page. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Hosted on GitHub Pages. Three.js and GSAP load from cdnjs, fonts from Google Fonts.

This is my own page. It is not made by or connected to Reonic.
