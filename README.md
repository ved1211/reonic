# Reonic x Ved

My application page for the AI Product Manager Intern (AI x Greentech) role at Reonic in Augsburg.

The page shows what I made for this application:

1. **A feedback sorter prototype** that files customer feedback as Bug, Feature request, Question or Praise and gives it a priority. It uses keyword rules in plain JavaScript, with no backend and no API keys. The examples are paraphrased from Reonic's public Trustpilot reviews, without reviewer names.
2. **Sample release notes** for AI Single Line Diagram, once for installers and once for Reonic colleagues. Based only on Reonic's public product page.
3. **Edge cases I'd test** when creating an offer in Reonic. Based on public information only.

## Run it

It is a single static page. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Hosted on GitHub Pages. Three.js and GSAP load from cdnjs, fonts from Google Fonts.

This is my own page. It is not made by or connected to Reonic.
